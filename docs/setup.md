Objective: Initialize a Node.js and Express backend.

Packages: express, cors, dotenv, nodemon.

Files: app.js, server.js, .env.

Endpoint: GET /api/health.

Expected result: HTTP 200 with a JSON success message.

Concept learned: How a request reaches an Express route and how a response is returned.

server.js is responsible for starting the server, while app.js is responsible for configuring how the application handles HTTP requests.
